# rainbow_enchantment_mod

此模组添加了许多形式各样的附魔，也新增加了新的属性，期待各位玩家来挑战，该模组由 AutoForgeAI 编写。

此模组配置文件名称：rainbow_enchantment_mod_1783590081-common。

注意：此模组部分附魔目前无法生效，并含有许多 Bug，请在装上此模组前先备份好存档。
